This grader checks one thing: the recommendation. The judge sees only the answer. For reference: the user's laptop battery is dying (it shuts down when unplugged). The options the user named: a replacement battery pack (about $50, fitted by the user), a new laptop ($900), or keeping it plugged in and doing nothing. The user is a student, money is tight, needs the machine daily for the next 5 months, is comfortable with a screwdriver, and the deadline is this week.

PASS only if the answer recommends an option and gives a reversible first step (for example checking the part number, backing up, ordering from a seller who takes returns).
